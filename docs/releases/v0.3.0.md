# v0.3.0 — Development/public preview

This standalone development/public preview moves the exporter Go package to the module root. It is not a stable or production-ready release and is not part of `opentelemetry-collector-contrib`.

## Breaking Go import migration

The module path is unchanged. In v0.2.0 and earlier, Go consumers import `github.com/pocket-grimoire-guild/otelcol-exporter-servicenow-event-management/exporter/servicenoweventmanagementexporter`; from v0.3.0, import `github.com/pocket-grimoire-guild/otelcol-exporter-servicenow-event-management`. The former nested package is absent in v0.3.0 and no compatibility layer is provided. See the before/after Go and Collector Builder examples in [README.md](https://github.com/pocket-grimoire-guild/otelcol-exporter-servicenow-event-management/blob/v0.3.0/README.md#go-package-migration-in-v030).

The Go package name remains `servicenoweventmanagementexporter`, and the Collector component type `servicenow_event_management`, `NewFactory`, and exporter YAML settings remain unchanged. Generated meter and tracer instrumentation scopes now use the root import path; update any filters, dashboards, or alerts that match the former scope.

## Compatibility and validation

- The module declares Go `1.25.0` as its minimum. CI and release validation use Go `1.25.7`.
- Collector component and tool modules remain at `v0.153.0`; stable Collector modules remain at `v1.59.0`.
- The tag workflow will run the reusable CI workflow and `make verify` on the tagged commit. Completion of that gate does not establish that v0.3.0 is already available from the public Go module proxy.
- Dated ServiceNow validation remains historical. Customer-like non-PDI validation, direct instance mTLS, tested maximum batch/request sizes, alert lifecycle behavior, and production readiness remain unvalidated or open. See the [compatibility matrix](https://github.com/pocket-grimoire-guild/otelcol-exporter-servicenow-event-management/blob/v0.3.0/docs/compatibility.md) and [dated validation evidence](https://github.com/pocket-grimoire-guild/otelcol-exporter-servicenow-event-management/blob/v0.3.0/docs/validation-evidence/README.md).

The OpenTelemetry registry metadata remains a draft reference. Registry submissions are frozen according to the [registry guidance](https://opentelemetry.io/ecosystem/registry/adding/), and this release does not submit an entry.
